# Reference Baseline Summaries

Summary CSV files used for baseline comparisons in `v2_surrogate_q1.py` and `v2_spqc550_hardware.py`:

- `table1_surrogate_ablation.csv`: `02_train -> 03_val` benchmark metrics for the `M4_PIMT_Physics_Only` and `M5_PIMT_Hybrid_Ensemble` multi-task baselines.
- `table4_spqc550_hardware_vs_classical.csv`: SPQC-550 and classical solver summary metrics for the six earlier full-grid reference-chain Ising tasks.
