## 二、选题快速决策建议

1. **若团队希望“稳扎稳打、图表丰富、英文故事好写、零外部环境折腾” -> 首选 C 题**
   - 数据全部是现成干净的 CSV，题目连用什么检验（至少两种非参数检验）、输出哪几个距离（`50 m`、`100 m`、`150 m` 下 `Npenguins` 取中位数）的预测数值表、甚至敏感性分析参数（阈值从 `0.5` 提到 `0.6/0.7`，相关性下降 `5%–20%`）都明确给出了，几乎没有理解偏差风险。
2. **若团队偏好“硬核工科物理背景、数学公式漂亮、3D 视觉冲击力强” -> 首选 B 题**
   - 仅 3 道大题，逻辑链条极其清晰：**三维光谱去噪连续重构 -> 氧气/烟气重构与变流量动态时滞辨识 -> 跨模态对齐实时软测量预测**。10 炉完整数据自包含，非常适合用函数型数据分析（FDA）/样条曲面 + 物理输运变时滞模型 + PLS/LightGBM/状态空间模型做出高区分度论文。
3. **若团队对“量子计算 QUBO 转化”感兴趣 -> 可选 D 题**
   - 本地 `03_往年真题与优秀论文拆解/2024_D题优秀论文_云计算资源预测与QUBO量子求解.pdf` 就是玻色量子同系列赛题的获奖范文，QUBO 编码套路（One-hot 约束惩罚项、系数离散化）高度可借鉴。
